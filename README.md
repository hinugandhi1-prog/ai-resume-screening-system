# 🧠 AI Resume Screening System

An intelligent Resume Screening System built using **Natural Language Processing (NLP)** and **Machine Learning** that automates the recruitment process by matching resumes with job descriptions.

---

## 🎯 Project Overview

This system helps recruiters and candidates by providing two powerful features:

### 📄 1. Job Description → Resume Matching
- Upload multiple resumes
- Compare with a job description
- Get match score using cosine similarity
- View detailed analysis and recommendations

### 🔍 2. Resume → Best Job Match
- Upload a resume
- System compares it with multiple job roles
- Suggests the **best suitable job role**
- Displays comparison graph for all roles

---

## 🧠 Technologies Used

- Python 🐍
- Streamlit (Frontend UI)
- Scikit-learn (TF-IDF & Cosine Similarity)
- PyPDF2 (PDF text extraction)
- Matplotlib (Graphs & Visualization)

---

## ⚙️ How It Works

1. Extract text from PDF (Resume / JD)
2. Clean and preprocess text
3. Convert text into vectors using TF-IDF
4. Compute similarity using cosine similarity
5. Generate:
   - Match Score
   - Suggestions
   - Best Job Role (if applicable)
